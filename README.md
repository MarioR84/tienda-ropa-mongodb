# Tienda de Ropa MongoDB

## Descripción

Proyecto desarrollado para el curso **Desarrollo con Plataformas Abiertas**.

Este proyecto implementa una base de datos NoSQL utilizando **MongoDB Atlas**, diseñada para administrar una tienda de ropa mediante diferentes colecciones.

## Tecnologías utilizadas

* MongoDB Atlas
* MongoDB Compass
* GitHub
* JavaScript

## Colecciones implementadas

* Usuarios
* Marcas
* Prendas
* Ventas

## Integrantes

* Mario Rodríguez

## Descripción de las colecciones

* **Usuarios:** almacena información de los clientes.
* **Marcas:** registra las marcas disponibles.
* **Prendas:** contiene los productos de la tienda.
* **Ventas:** registra las compras realizadas por los clientes.
